# Programación Multimedia (PMUL)

Trabajos de **Programación Multimedia y Dispositivos Móviles**.

## `libgdx/` — Juego con libGDX

Proyecto de juego con el framework **libGDX**:

- `Assets.java` — gestor de recursos.
- `assets/fuentes/` — fuentes bitmap (`.fnt` + `.png`).
- `assets/graficos/` — atlas de sprites (`atlas.atlas` + `atlas.png`) y fondo.
- `assets/sonidos/` — efectos de audio (`.mp3`).

## Requisitos

- JDK 8+.
- libGDX (abrir con el plugin de libGDX en el IDE o con Gradle).
