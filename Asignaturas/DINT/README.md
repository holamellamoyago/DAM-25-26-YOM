# Desarrollo de Interfaces (DINT)

Trabajos de **Desarrollo de Interfaces**: interfaces gráficas con Java Swing y generación de informes con JasperReports.

## Contenido

### `AA Preparacion Examen/` — Preparación de examen
- `ExamenYagoOtero` — aplicación Swing con JasperReports: gestión de usuarios y reportes (`.jrxml`: `Tarefa1`, `TareaInformes1`, `TarefaHistorial`, `TarefausuarioIndividual`), diálogos, frames y sistema de ayuda JavaHelp.
- `PlantillaExamen` — plantilla con informes (`Pilotos2.jrxml`) y help JavaHelp.

### `LoginSupabase/` — Login con Supabase
Aplicación Swing que autentica contra **Supabase** (`SupabaseAuth`, `SupabaseConfig`).

### `MyReports/` — Informes JasperReports
Ejercicios de informes (`.jrxml`): `Blank_A4`, `Ejercicio2`, `ListaContactos`, etc.

### `INFORMES/LIB/` — Librerías
JARs de JasperReports y dependencias (Jackson, OpenPDF, etc.) usados por los proyectos anteriores.

## Requisitos

- JDK 8+ y Eclipse (proyectos con `.classpath`/`.project`).
- JasperReports 7.0.3 y dependencias: incluidas en `lib/` de cada proyecto.
