Introducción

Esta aplicación ha sido desarrollada para facilitar la gestión de usuarios y la consulta de información mediante una interfaz gráfica sencilla.

El sistema de ayuda proporciona información sobre el uso de las distintas ventanas, formularios y opciones disponibles en la aplicación.

¿Cómo utilizar la ayuda?

  • Pulse la tecla F1 para acceder a la ayuda contextual.
  • Utilice el menú Ayuda para consultar el contenido completo.
  • Navegue por la tabla de contenidos para acceder a los distintos temas.

Contenido de la aplicación

A lo largo de esta ayuda encontrará información sobre:

  • Registro de usuarios.
  • Consulta y generación de reportes.
  • Acciones disponibles en cada ventana.
