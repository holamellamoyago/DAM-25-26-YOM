# Sistemas de Gestión Empresarial (SXE)

Trabajos de **Sistemas de Gestión Empresarial** con **Odoo 17**.

## `Colegio/` — Módulo Odoo

Módulo de Odoo 17 para la gestión de un colegio:

- `__manifest__.py` — definición del módulo (v17.0.1.0.0).
- `models/aula.py` — modelo `Aula`.
- `views/views.xml` — vistas (formulario, árbol, acciones).
- `security/ir.model.access.csv` — reglas de acceso.

### Instalación

Copia la carpeta `Colegio` al directorio `addons` de tu instancia Odoo 17, actualiza la lista de aplicaciones e instálalo.

> Los enunciados y entregas (PDF) de la asignatura están en [`../../docs/apuntes/`](../../docs/apuntes/) (`OteroYagoobligatoria1/2/3.pdf`, `Unidad 5.pdf`, `VigRacing.odt`).
